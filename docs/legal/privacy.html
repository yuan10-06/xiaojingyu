「小鲸鱼：会记住你的桌宠」隐私政策

生效日期：2026 年 11 月 3 日　|　更新日期：2026 年 11 月 8 日　|　适用版本：Android 9.15.6（包名 com.ganfanyu.app）

「小鲸鱼：会记住你的桌宠」是一款本地优先的人工智能陪伴应用。开发者不运营用于存储聊天记录的服务器，你的聊天记录、记忆库、人设与设置默认只保存在本机。只有在生成回复、查询天气或使用语音等功能时，应用才会按本政策将必要信息发送给对应的第三方服务。

02我们处理哪些信息

2.1 你主动提供的信息

信息使用场景处理目的是否离开设备
大模型 API Key 你在设置中自行填写 作为身份凭证直连模型服务，产生对话 仅发送给你所选择的模型服务商；不上传开发者服务器
聊天内容、人设、记忆与情绪状态 日常对话与长期记忆 生成符合人设的回复、维持对话连续性 生成回复时发送给模型服务商；本地另存一份
你主动上传的图片 拍照识图、发送图片 理解图片内容并生成回复 发送给模型服务商；未发送时仅在本机
语音输入 按住说话 转换为文字后参与对话 由系统语音识别或手机厂商服务处理

2.2 经你授权后才会读取的信息

权限 / 信息功能处理方式拒绝后的影响
位置（粗略 / 精确） 确定你所在城市、天气，以及你与角色的相对距离 经纬度会发送给 Open-Meteo、Photon、BigDataCloud 用于城市识别与天气查询；不保存轨迹 可手动选择城市，功能基本可用
相机 AR 桌宠、拍照识图 画面默认在本机处理；仅当你主动发送图片时才上传 无法使用 AR 与拍照，文字对话不受影响
麦克风 语音输入 调用系统语音识别，可能由手机厂商处理音频 可改用键盘输入
设备传感器列表 TapTap 账号登录、防沉迷实名认证组件的运行环境自检 仅在你点击隐私政策弹窗「同意并继续」、并完成 TapTap 登录后，由 TapTap SDK 读取本机传感器列表用于运行环境检测；不采集传感器数据内容，不上传开发者服务器 无法使用 TapTap 登录与防沉迷功能，其余功能正常
设备标识符（Android ID、OAID） TapTap 账号登录、防沉迷实名认证与运行环境安全校验 仅在你点击隐私政策弹窗「同意并继续」后，由 TapTap SDK 读取；不用于广告投放或用户画像，不写入开发者服务器；不同意不会初始化 SDK 无法使用 TapTap 登录与防沉迷功能，其余功能正常
日历（只读） 读取当天日程，用于展示与提醒 仅在设置页授权后读取标题、时间、地点；默认仅在本机使用 无法显示今日待办，其他功能正常
应用使用情况 判断你当前是否正在使用手机，减少打扰 需你在系统设置中手动授权；仅在本机判断，不建立行为画像 主动消息可能变多，其他功能正常
通知 消息提醒 由系统通知服务展示 收不到提醒，应用内仍可查看
悬浮窗 桌面悬浮桌宠 仅用于显示桌宠窗口 无法显示悬浮桌宠
后台运行 / 电池优化白名单 保持陪伴服务与提醒存活 不读取内容，仅维持进程 应用可能被系统清理，需重新打开

2.3 应用自动产生的信息

  • 本地运行日志、崩溃信息：仅保存在本机应用私有目录，用于排查问题；卸载即删除。
  • 网络状态：用于判断是否可以请求模型或天气服务。
  • 应用内虚拟状态（情绪、关系值、金币与道具）：属于应用内数据，仅保存在本机。

2.4 我们不会收集的信息

  • 通讯录、短信、通话记录、相册全量内容（只有你主动选择的图片会被读取）。
  • 广告标识符（OAID / IDFA）、应用安装列表。
  • 持续定位轨迹、精确定位历史。
  • 身份证号、银行卡号、人脸生物特征模板（相机人脸检测在本机完成，不上传）。

03信息如何共享给第三方

除下列情形及法律法规要求外，开发者不会向第三方提供你的个人信息，也不会出售或出租。

第三方用途涉及信息说明
DeepSeek（杭州深度求索人工智能基础技术研究有限公司） 生成对话回复、文本与图片理解 对话内容、必要上下文、你发送的图片 由你自行配置 API Key 直连；其处理规则以 DeepSeek 官网公布的政策为准
Open-Meteo（瑞士） 天气查询 城市名或经纬度 不含聊天内容与身份信息
Photon / komoot（德国）、BigDataCloud（澳大利亚） 地名搜索、经纬度转城市 城市名或经纬度 不含聊天内容与身份信息
MiniMax 查询 API Key 余额与套餐 你填写的 Key、账户用量 仅当你主动配置该服务时启用
系统语音识别 / 文字转语音 语音输入与朗读 语音音频或待朗读文本 由操作系统或手机厂商服务处理，开发者无法控制其规则
TapTap（易玩（上海）网络科技有限公司） 应用分发与更新、TapTap 账号登录、防沉迷实名认证 设备标识符（Android ID、OAID）、设备型号与系统版本、网络状态、设备传感器列表、下载与安装信息；实名认证所需的姓名与身份证号由 TapTap 直接收集与核验，不经过开发者 按 TapTap 自身隐私政策处理；设备标识符仅用于登录、实名与安全风控，不用于广告；登录与实名功能在你同意本政策后才会启用
跨境传输提示：Open-Meteo、Photon / komoot、BigDataCloud 的服务器位于境外。当你授权定位或手动选择城市时，城市名或经纬度可能被传输至境外用于返回天气与地名结果。该等信息不包含你的聊天内容、姓名或账号。你可以不授权定位并手动填写城市，或在系统设置中关闭定位权限。

04权限使用

应用申请的每一项 Android 权限都对应明确功能，且除基础联网与保活外均为可选。完整清单（含拒绝授权的影响与撤回方式）见 《权限使用清单》。

你可以在「系统设置 → 应用 → 小鲸鱼：会记住你的桌宠 → 权限」中随时关闭定位、相机、麦克风、日历、通知、悬浮窗等权限；关闭后仅对应功能不可用，不影响文字对话。

05保存期限与安全措施

  • 本地数据：聊天记录、记忆库、人设、设置保存在应用私有目录，直至你主动删除或卸载应用。卸载后应用私有数据会被系统清除（你自行导出的文件除外）。
  • API Key：仅保存在本机应用私有存储，不写入日志、不上传开发者服务器。请勿将 Key 截图分享给他人；如怀疑泄露，请在模型服务商处重置。
  • 云端：开发者不运营存储用户内容的服务器，因此不存在由开发者持有的云端副本。但对话内容会发送给模型服务商，其保存期限与安全措施受其自身政策约束。
  • 设备风险：如设备丢失或被他人使用，本地数据可能被读取。建议启用系统锁屏与应用锁。

06你的权利

  • 查阅与复制：你可以在应用内查看聊天记录、记忆与设置；如应用提供导出功能，可自行导出。
  • 更正：你可以修改人设、城市、称呼等设置，或删除不准确的记忆。
  • 删除：可删除单条对话、清空记忆；卸载应用可清除全部应用私有数据。由于开发者不持有云端副本，无需额外向开发者申请删除。
  • 撤回授权：在系统设置中关闭对应权限。
  • 注销：本应用无账号体系，卸载即视为终止使用并清除本地数据。
  • 投诉与咨询：通过 GitHub Issues 联系，我们将在 15 个工作日内答复。

行使上述权利不会导致你无法使用与权利无关的基础功能。

07未成年人保护

  • 本应用面向具备完全民事行为能力的用户，建议 18 周岁以上使用。
  • 未满 14 周岁的未成年人不得在无监护人同意与陪同的情况下使用；14 至 18 周岁的未成年人应在监护人同意与指导下使用。
  • 应用内不提供充值、打赏或付费抽奖，虚拟金币与道具仅通过本地互动获得，不具有现实货币价值。
  • AI 生成内容可能不符合未成年人的认知，监护人应指导使用；如发现未成年人未经同意使用，可卸载应用并联系我们。

08人工智能生成内容

应用中的对话回复、部分文本与图像理解结果由第三方大模型生成，可能不准确、不完整或与事实不符。我们通过界面提示、设置页说明与分发页面标注等方式进行标识。具体范围、标识方式与禁止行为见 《人工智能生成内容说明》。

09政策更新

当功能、第三方服务或法律要求发生变化时，我们会更新本政策并修改页面顶部的更新日期。涉及处理目的、信息类型或共享对象的重大变更，我们会在应用内或分发页面显著提示；变更生效后你继续使用，视为接受更新后的政策。
