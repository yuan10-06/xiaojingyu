# 常见问题

## 没有 API Key 能用吗？

可以启动和体验界面、开屏、桌宠和本地功能；聊天需要配置 DeepSeek（或 OpenAI 兼容）API Key。

## API Key 存在哪里？

只保存在本机，不写入仓库。桌面版默认数据目录是 `%LOCALAPPDATA%\BrainN`。

## 聊天记录会上传吗？

聊天和记忆默认保存在本地。只有调用大模型时，当前对话才会发送到你配置的 API。

## 为什么安装后开屏身份是默认的？

安装新用户版时会重置开屏身份，避免把开发者的名字和密码带到新用户机器。

## 为什么每次安装初始人设都不同？

新用户版安装时会清掉旧种子和旧人设覆盖，首次启动重新随机；聊天记录和记忆库不会被删除。

## 人格页城市和天气城市不一致？

正常版本会在启动时把天气城市同步到人设城市。如果你看到不一致，请升级到 v9.10 或更新版本。

## 点“预览开屏”没反应？

v9.10 已修复：主页重载后仍会保留开屏 API，预览会重新播放；如果仍然无效，请附上日志提 Issue。

## 没有声音/语音？

检查设置里的音色、音量、系统和浏览器权限；部分音色依赖本地素材。

## Windows 提示“未知发布者”？

安装包未签名，SmartScreen 会提示。核对 Release 里的 SHA256 后选择“更多信息 → 仍要运行”。

## Android 安装失败？

需要允许“安装未知应用”；不同厂商的限制不同。构建源码需要 JDK 17、Android SDK 和 Chaquopy。

## 卸载会删除聊天记录吗？

不会。卸载只移除程序；数据目录需要手动删除。

## 2D 形象不显示？

仓库不包含第三方 Live2D 模型、字体和 Cubism Core，需要自备有授权的素材，见 [ASSETS_NOT_INCLUDED.md](ASSETS_NOT_INCLUDED.md)。

## 关掉 TapTap 后小鲸鱼黑屏 / 像断网？

如果你是在 TapTap 的小窗、云玩或秒玩里打开小鲸鱼，关闭 TapTap 会结束整个会话，本地服务也会一起停掉，所以会黑屏或像断网。请先从 TapTap 下载安装，再从手机桌面的「小鲸鱼」图标启动；独立启动时 App 有前台服务，切后台不会中断。

## 余额为什么查不到？

余额查询只支持 DeepSeek 官方接口（https://api.deepseek.com）。如果你填的是第三方中转站 Key，或者 Key 无效 / 无权限 / 网络超时，设置页会显示对应原因。保存 Key 后需要等大脑重启完成，再点「刷新余额」。
