- 修复桌面快捷方式图标空白、exe 名称、开屏回车穿透和预览开屏偶发失效。
- Android 桌宠支持摇一摇碰撞和重力反馈。

## 安装说明

1. 下载安装包。
2. 安装包未签名，Windows SmartScreen 提示时选择“更多信息 → 仍要运行”。
3. 安装时会重置初始人设；聊天记录和记忆库不会被删除。
4. 首次启动填入 DeepSeek API Key，也可以先跳过。

数据默认保存在 `%LOCALAPPDATA%\BrainN`。

## 已知问题

- 安装包未签名，部分安全软件可能误报；请核对上面的 SHA256。
- 仓库不包含第三方 Live2D 模型、字体和 Cubism Core；2D Live2D 形象需要自备有授权的素材。
- 开屏中的 DeepSeek 标识仅用于说明兼容性，本项目与 DeepSeek 官方无关。
